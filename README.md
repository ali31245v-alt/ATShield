# AT Shield

تطبيق Android تجريبي لتفعيل VPN محلي مع خوادم DNS عائلية. المشروع يبني نسخة debug عبر GitHub Actions.

افتح Actions ثم Build APK، وبعد نجاح البناء نزّل artifact باسم AT-Shield-debug-apk.

ملاحظة: هذا البناء يستخدم VPN وDNS آمنين كقاعدة أولية؛ ليس فلتر DNS كامل الحزم، ولا يمنع حذف التطبيق على جميع أجهزة Android.
